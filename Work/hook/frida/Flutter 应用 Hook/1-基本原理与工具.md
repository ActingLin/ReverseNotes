# Flutter 应用 Hook 基本原理

## 14.1 基本原理

Flutter 应用编译后包含:
- `libflutter.so` — Flutter 引擎
- `libapp.so` — Dart 编译后的业务代码

Dart 业务代码会被编译为 AOT 快照,运行在 Flutter 引擎内。Hook Dart 函数有两种方式:

1. **IDA/Ghidra 静态定位偏移** → 通过 `Module.findBaseAddress("libapp.so").add(offset)` 动态 Hook
2. **工具辅助分析** → 使用 blutter 等工具自动还原类名、方法名和偏移

## 14.4 常用 Flutter 逆向工具

| 工具 | 用途 |
|------|------|
| [blutter](https://github.com/aspect-apps/blutter) | 自动分析 libapp.so，输出类名、方法名和偏移 |
| [Doldrums](https://github.com/AeonLucid/Doldrums) | Dart AOT snapshot 反序列化工具 |
| [reFlutter](https://github.com/aspect-apps/reFlutter) | Flutter 反编译/重打包工具 |
| IDA Pro / Ghidra | 静态分析 libapp.so |

## 使用建议

- Hook Dart 函数时,`args[0]` 通常是 `Dart State` 指针,需要结合 blutter 输出的结构体偏移读取参数
- Dart 字符串不是 C 字符串,不能直接 `Memory.readUtf8String`,需要读取对象头后再取数据区
- 优先用 blutter 拿到符号表再下 Hook,避免纯靠猜偏移
