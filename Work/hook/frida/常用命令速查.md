# Frida 常用命令速查

## 1.2 命令行启动方式

```bash
# USB 模式 - 附加到已运行的 App
frida -U -l hook.js com.example.app

# USB 模式 - spawn 模式启动（推荐，能 hook 到启动阶段代码）
frida -U -f com.example.app -l hook.js --no-pause

# 转发端口（远程调试）
adb forward tcp:27042 tcp:27042
frida -H 127.0.0.1:27042 -l hook.js com.example.app
```

## 附录 A. 常用命令速查

```bash
# 列出正在运行的进程
frida-ps -U

# 列出已安装的 App
frida-ps -Ua

# 列出所有进程（包括系统进程）
frida-ps -Uai

# 查看 App 版本
frida --version

# 生成离线注入脚本
frida -U -f com.example.app -l hook.js --no-pause -o output.log

# 使用 frida-trace 自动 hook
frida-trace -U -f com.example.app -i "Java_com_example_*"
frida-trace -U -f com.example.app -j "*!*encrypt*/i"
```
