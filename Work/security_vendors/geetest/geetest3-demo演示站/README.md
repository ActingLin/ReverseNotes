# 极验3 官方demo

## 古法逆向 学习总结
极验3防护
- 混淆
  - 字面量混淆，运行时解密，Unicode编码，混淆控制流状态码
  - 逻辑混淆，控制流平坦化
- 检测
  - 这个官方demo其实只检测了第三次的w,但是为了学习和以备不时之需把前两个w生成过程也扣出来
- 图片乱序

项目包含
- ai+ast解混淆相关skill(内含常见解混淆规则)的纯ai解混淆，实测是可用的，可以文件替换
- 自己搜集学习并实战ast解混淆代码，代码压缩一半，逻辑还原方便调试，后续还可以继续优化ast脚本，去除逗号表达式和替换常量进一步提升代码可读性
- 解混淆代码，通过reqable文件替换在chrome浏览器调试并扣代码，还原了三次w的计算，加密方式基本上是一样的不过调用链不同
  - 第一个w: 生成aeskey(没有就生成),搜集并加密浏览器指纹
  - 第二个w: 使用toString进行代码格式化检测并生成captcha_token,获取鼠标到滑块弹出前的轨迹(轨迹体现在跟着你转的那个扇形),只能用一次并检测复用,页面加载时间差和时间链记录,复用前面生成aeskey获取,前面响应中的s值和浏览器指纹,进行aes加密并md5签名各部分
  - 第三个w: 搜集滑动轨迹+滑动x坐标(图片乱序的,后续自己识别并计算,先还原后图片使用opencv识别x距离)+滑动时间+页面加载时间差和时间链记录,中间进入了动态文件gct.js进行了一系列函数等检测,但最后只生成h9s9的值,还是个随机的,直接固定它,最后将前面搜集的数据,使用响应中新的challenge,c和s值,进行aes加密生成第三个w;轨迹生成可以使用算法生成，这个需要经验积累
