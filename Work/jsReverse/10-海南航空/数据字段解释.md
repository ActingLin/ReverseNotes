## 航班数据核心字段采集汇总表

### 一、航班基础信息

| 字段路径（简化） | 示例值 | 含义与用途 |
| :--- | :--- | :--- |
| `flightSegments[].operatingAirlineCode` | `UQ`、`HU` | 实际承运航司二字码，识别航司品牌 |
| `flightSegments[].marketingAirlineCode` | `UQ`、`8L` | 营销航司代码（可能与承运不同） |
| `flightSegments[].flightNumber` | `2522`、`7641` | 航班号，唯一标识 |
| `flightSegments[].departureAirportCode` | `CSX`、`LHW` | 出发机场三字码 |
| `flightSegments[].arrivalAirportCode` | `LHW`、`SZX` | 到达机场三字码 |
| `flightSegments[].departureTime` | `14:40`、`11:00` | 计划起飞时刻 |
| `flightSegments[].arrivalTime` | `17:15`、`18:40` | 计划到达时刻 |
| `flightSegments[].departureDate` | `2026-07-28` | 起飞日期（用于跨天判断） |
| `flightSegments[].arrivalDate` | `2026-07-28` | 到达日期 |
| `flightSegments[].duration`（分钟） | `155`、`190` | 单个航段飞行时长 |
| `duration`（顶层，分钟） | `555`、`460` | 总行程时长（含中转） |
| `flightSegments[].ctStayDuration`（分钟） | `210` | 中转停留时长 |
| `flightSegments[].ctStayTime` | `3小时30分钟` | 中转停留时长（友好格式） |
| `overnight` | `false` | 是否过夜中转 |
| `acrossDay` | `0` | 是否跨天（0=当天到达） |
| `flightSegments[].stopQuantity` | `0` | 经停站数（0表示直飞航段） |
| `itineraryType` | `"2"` | 行程类型（2=中转，1=直飞） |
| `flightSegments[].aircraftCode` | `738`、`33E` | 机型代码 |
| `flightSegments[].displayAircraftName` | `波音737-800` | 机型名称（展示用） |
| `flightSegments[].departureTerminal` | `T2` | 出发航站楼 |
| `flightSegments[].arrivalTerminal` | `T3` | 到达航站楼 |

### 二、价格与税费

| 字段路径（简化） | 示例值 | 含义与用途 |
| :--- | :--- | :--- |
| `minLowPrice`（不含税） | `1220` | 成人最低票面价（不含税） |
| `minLowPriceWithTax`（含税） | `1520` | 成人最低含税总价（用户实付） |
| `taxPrice` | `300` | 总税费（燃油附加费+民航基金） |
| `fullYFare` | `1840`、`1400` | Y舱全价（用于计算折扣） |
| `discount` | `0.23`、`0.36` | 折扣系数（票价/全价） |
| `airItineraryPrices[].travelerPrices[].travelerType` | `ADT`、`CHD`、`INF` | 旅客类型（成人/儿童/婴儿） |
| `travelerPrices[].baseFare` | `1220` | 对应旅客类型的票面价（不含税） |
| `travelerPrices[].totalFare` | `1520` | 对应旅客类型的含税总价 |
| `travelerPrices[].taxs[].code` / `amount` | `YQ:200`, `CN:100` | 燃油附加费（YQ）和民航基金（CN）明细 |

### 三、舱位与库存

| 字段路径（简化） | 示例值 | 含义与用途 |
| :--- | :--- | :--- |
| `flightBookingClasses[].bookingClass` | `F`、`N`、`V`、`A` | 订座子舱位，影响退改和积分 |
| `flightBookingClasses[].inventoryQuantity` | `2`、`10` | 该舱位剩余座位数（数字） |
| `flightBookingClasses[].inventoryStatus` | `"A"`（有票）、`"NS"`（无座） | 库存状态码 |
| `inventoryQuantityY` / `C` / `W`（顶层） | `"A"`、`"NS"` | 分舱位库存汇总（快速判断） |
| `overTake` | `false` | 是否超售或抢票状态（如“余票紧张”） |

---

### 四、行李与机上服务

| 字段路径（简化） | 示例值 | 含义与用途 |

| `benefits[code="MEAL"].remark` | `无免费机上餐饮` / `提供机上餐点或小食` | 餐食服务说明 |

| `flightSegments[].mealText` | `午餐` | 餐食类型（如早餐/午餐） |
| `benefits[code="EARLY-SEAT"].remark` | `第6排起提前选座` | 选座权益 |
| `benefits[code="INTERLINE_BAGGAGE"].remark` | `一票到底、行李直挂` | 中转行李直挂服务 |

### 八、唯一标识与元数据

---

> **备注**：  
> - 所有价格单位均为人民币（CNY）。  
> - 时间格式为 `HH:mm`，日期格式为 `YYYY-MM-DD`。  
> - 库存状态 `"A"` 表示有余票，`"NS"` 表示无座，`"SO"` 表示售罄。  
> - 采集时建议关注高频变化字段（价格、库存、退改手续费）以支撑动态监控。
