# 海南航空航班数据采集系统 — 操作手册

## 一、环境准备

### 1.1 Python 版本
需要 Python **3.10+**，确保已安装并可执行 `pip`。

### 1.2 安装依赖
```bash
pip install -r requirements.txt
```

依赖清单：

| 包名 | 用途 |
| :--- | :--- |
| `requests` | HTTP 请求，调用海航 API |
| `pymysql` | MySQL 数据库连接 |
| `loguru` | 日志输出 |
| `PyExecJS` | 执行 JS 签名脚本（`hmac_sha1.js`） |

### 1.3 Node.js（签名依赖）
脚本通过 `execjs` 调用 Node.js 执行签名逻辑，需要安装 Node.js：
- 下载：https://nodejs.org/
- 安装后确认：`node --version`

### 1.4 创建数据库
登录远程 MySQL，执行：
```sql
CREATE DATABASE IF NOT EXISTS flight_monitor DEFAULT CHARSET utf8mb4;
```

## 二、配置

### 2.1 修改数据库连接信息
编辑 [db_config.py](db_config.py)：

```python
DB_CONFIG = {
    "host": "xxx.xxx.xxx.xxx",       # 远程数据库 IP
    "port": 3306,                  # 端口
    "user": "spider_demo",         # 用户名
    "password": "spider_demo",     # 密码
    "database": "flight_monitor",  # 数据库名
    "charset": "utf8mb4",
    "connect_timeout": 10,
}
```

### 2.2 修改采集参数
编辑 [hainan_search.py](hainan_search.py) 中 `data["data"]["originDestinations"]` 部分：

出发地和目的地机场三字码需要自己构建获取，网站中没有API能直接获取完整的三字码
```python
"originDestinations": [
    {
        "departureDate": "2026-07-28",  # 出发日期
        "destination": "SZX",           # 目的地机场三字码
        "origin": "CSX",                # 出发地机场三字码
        "destinationType": "1",
        "originType": "1"
    }
],
"passenger": "ADT:1,CNN:1,INF:1",       # 旅客类型和数量
```

旅客类型说明：`ADT`=成人, `CHD`=儿童, `INF`=婴儿, `CNN`=儿童不占座。

## 五、数据表结构

表名：`flight_itineraries`

| 分类 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **标识** | `id` | BIGINT | 自增主键 |
| | `trip_id` | VARCHAR(255) | 行程唯一标识 |
| | `crawl_time` | DATETIME | 采集时间 |
| **航班** | `dep_airport` / `arr_airport` | CHAR(3) | 起降机场三字码 |
| | `dep_date` / `dep_time` / `arr_time` | DATE/TIME | 起降日期时刻 |
| | `airline_code` / `flight_no` | CHAR(2)/VARCHAR | 航司代码/航班号 |
| | `itinerary_type` | TINYINT | 1=直飞, 2=中转 |
| | `across_day` | TINYINT | 0=当天, 1=跨天 |
| **价格** | `price_no_tax` | DECIMAL | 票面价（不含税） |
| | `price_with_tax` | DECIMAL | 含税总价 |
| | `tax_amount` | DECIMAL | 税费合计 |
| | `discount` | DECIMAL | 折扣系数 |
| **舱位** | `booking_class` | VARCHAR(5) | 子舱位代码 |
| | `inventory_qty` | INT | 剩余座位数 |
| | `over_take` | TINYINT | 0=正常, 1=余票紧张 |
| **服务** | `luggage_free` | VARCHAR(50) | 免费托运行李 |
| | `luggage_carry` | VARCHAR(50) | 手提行李规格 |
| | `meal_service` | VARCHAR(50) | 餐食说明 |
| | `refund_rule` | VARCHAR(200) | 退票规则摘要 |
| **中转** | `segment_count` | TINYINT | 航段数 |
| | `stay_duration` | INT | 中转停留分钟 |
| | `overnight` | TINYINT | 是否过夜中转 |
| **其他** | `aircraft_name` | VARCHAR(50) | 机型 |
| | `total_duration` | INT | 总行程分钟 |
| | `raw_json` | JSON | 完整原始数据 |

去重策略：`trip_id + crawl_time` 联合唯一索引，`INSERT IGNORE` 自动跳过重复记录。

## 六、常见问题

### Q1: 签名失败 / `hnairSign` 无效
可能是 header 中的 `ekingCode` 过期，需要从海航移动端页面重新抓取。

### Q2: 入库失败 "Access denied"
检查 `db_config.py` 中的用户名/密码是否正确，以及该用户是否有对应数据库的写入权限。

### Q3: 远程数据库连接超时
- 检查 IP 和端口是否正确
- 确认远程 MySQL 已开启外网访问（`bind-address = 0.0.0.0`）
- 确认防火墙/安全组已放行 3306 端口
- 可以调大 `connect_timeout` 值

### Q4: `INSERT IGNORE` 导致重复采集时不更新
设计如此。需要价格变化追踪时，建议查询时按 `trip_id` 分组取最新 `crawl_time`，或额外建一张价格变更表。

## 七、扩展建议

### 定时采集（Linux cron / Windows 任务计划）
```bash
# Linux crontab 示例：每天 6/12/18/22 点各采一次
0 6,12,18,22 * * * cd /path/to/project && python hainan_search.py >> crawl.log 2>&1
```

### 批量航线采集
将航线列表写在配置文件中，循环调用 API：
```python
routes = [
    ("CSX", "SZX"),
    ("CSX", "PEK"),
    ("HAK", "SHA"),
]
for origin, dest in routes:
    # 修改 originDestinations 后请求...
```

### 价格监控查询示例
```sql
-- 某航线当前最低价
SELECT dep_date, airline_code, flight_no, price_with_tax, crawl_time
FROM flight_itineraries
WHERE dep_airport = 'CSX' AND arr_airport = 'SZX' AND dep_date >= CURDATE()
ORDER BY price_with_tax ASC
LIMIT 10;
```
