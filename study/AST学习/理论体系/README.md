## 按场景查找

- **查节点长什么样** → 02
- **查某个 API 怎么用** → 03（速查）；03 里 scope 部分想深入 → 06，节点操作想深入 → 07
- **想把节点变回代码**（提取函数源码、生成最终结果）→ 04
- **想"执行"一段混淆代码拿结果**（解密函数、数组位移）→ 05
- **想安全地改名/判断变量能不能折叠** → 06
- **想安全地删/换/插节点** → 07
- **遇到一段混淆代码不知道是什么** → 08
- **要动手还原一个样本** → 09（套路）+ 上层目录的 01~04 实操系列
- **找工具/查资料** → 10
