### 7.3 AI 辅助反混淆（2024-2025 新趋势）

- **LLM + CoT 分阶段还原**：arXiv 论文《Analyzing Chain of Thought Approaches in Control Flow Code Deobfuscation》提出用推理模型分五阶段还原 CFF：混淆检测 → CFF 恢复 → 控制流重建 → 不透明谓词消除 → 代码清理。传统规则式工具缺乏系统推理策略，微调 LLM 受上下文窗口限制。
- **程序合成（CHISEL）**：OOPSLA 2024/2025 论文，用程序合成逆向控制流混淆，500+ 样本恢复率 86%，优于程序合成器/SOTA LLM/二进制优化器基线。
- **AI 逆向 skill**：xbsReverseSkill 等仓库把 AST 反混淆封装成 AI 可调用的 skill（分层、可回退、针对 `_0x`/字符串表/while+switch 分发链），覆盖 reese84、顶象、极验 4 等站点样本。
- **趋势判断**：AI 补充的是**规则式变换的不足**（分层混淆、CFF 变体识别），但**基础 AST 能力（本文档讲的内容）仍是所有 AI 方案的地基**。

### 7.5 推荐学习路径（由浅入深）

1. **第 1 步**：AST Explorer 上随手写代码看 AST 结构，理解 Program → Statement → Expression 的层级关系（1 天）
2. **第 2 步**：读完 babel-handbook 中文版，掌握 visitor + path 的核心 API（2-3 天）
3. **第 3 步**：手写小插件练手：var→let、删除 console、箭头函数转普通函数、常量名转大写（2 天）
4. **第 4 步**：用 `obfuscator.io` 生成混淆代码，对照本目录 08 篇识别特征，再用 09 篇套路逐步还原（3-5 天）
5. **第 5 步**：啃一个开源反混淆项目（推荐 JS-AST-Deobfuscator 或 kuizuo/js-deobfuscator）的源码，理解常量折叠、函数内联、控制流还原的实现细节（1 周）
6. **第 6 步**：拿真实网站 JS 练手（52pojie 案例、自己逆向中遇到的混淆代码），从普通 OB 混淆开始，再挑战定制混淆（长期）

## 附录：速查卡

### 反混淆脚本通用骨架（直接复制改）

```js
const fs = require('fs');
const parser = require('@babel/parser');
const traverse = require('@babel/traverse').default;
const t = require('@babel/types');
const generator = require('@babel/generator').default;

const code = fs.readFileSync('input.js', 'utf-8');
const ast = parser.parse(code, { sourceType: 'unambiguous' });

traverse(ast, {
  // 在此写你的 visitor 逻辑
  'StringLiteral|NumericLiteral'(path) {
    // 示例：常量折叠
    const { confident, value } = path.evaluate();
    if (confident && path.node.extra) {
      path.replaceWith(t.valueToNode(value));
    }
  }
});

fs.writeFileSync('output.js', generator(ast).code);
```

### 常用 t.xxx 速查

```js
t.identifier(name)                 // 标识符
t.stringLiteral(str)               // 字符串
t.numericLiteral(num)              // 数字
t.callExpression(callee, args)     // 函数调用
t.memberExpression(obj, prop, computed) // 成员访问
t.expressionStatement(expr)        // 表达式语句
t.valueToNode(value)               // 任意 JS 值 → 节点
t.blockStatement(body)             // 代码块
t.returnStatement(arg)             // return
t.binaryExpression(op, left, right) // 二元运算
t.ifStatement(test, consequent, alternate) // if
t.cloneNode(node, deep)            // 深拷贝节点
```

### 常用 path API 速查

```js
path.node / path.parent / path.parentPath  // 节点与父子
path.replaceWith(node) / path.remove()     // 替换与删除
path.replaceWithMultiple(nodes)            // 多节点替换
path.insertBefore(node) / path.insertAfter(node)  // 插入
path.unshiftContainer(key, n) / path.pushContainer(key, n)  // 容器插入
path.evaluate()                            // 常量求值
path.scope.getBinding(name) / hasBinding(name)  // 作用域（详见 06 篇）
path.scope.generateUidIdentifier(name)     // 唯一标识符
path.findParent(fn) / path.getFunctionParent()  // 祖先查找
path.skip() / path.stop()                  // 流程控制
path.isIdentifier() / path.isXxx()         // 类型判断
path.toString()                            // 当前节点 → 代码字符串
path.buildCodeFrameError(msg)              // 带位置报错
```

### 常用 scope / binding 速查（详见 06 篇）

```js
binding.constant / binding.references      // 判断能否折叠/删除
binding.referencePaths                     // 所有引用处（替换用）
binding.constantViolations                 // 所有赋值处（判断用）
scope.rename(oldName, newName)             // 安全重命名
scope.getOwnBinding(name) / scope.parentHasBinding(name)  // 改名冲突检查
```

### vm 沙箱执行速查（详见 05 篇）

vm.runInContext('var a = 1;', ctx);
